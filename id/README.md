# Kit Agen Cari Kerja & LinkedIn

Kit yang bisa dipakai ulang, netral terhadap platform, untuk agen AI yang membantu siapa saja mencari kerja dan merapikan profil LinkedIn. Bisa dipakai di Muse dan di Grok Bot. Tidak ada yang dikirim, di-submit, atau diterbitkan tanpa persetujuan pengguna, dan agen tidak boleh mengarang pencapaian, jabatan, tanggal, atau angka.

Skill ini bantu kamu dapat lebih banyak peluang kerja: mencari dan memverifikasi lowongan yang masih buka, merancang lamaran dengan gaya bahasamu, dan merapikan LinkedIn supaya lebih mudah ditemukan rekruter — tetap kamu yang putuskan setiap kali ada yang mau dikirim.

## File di folder ini

- `SOUL.md` — identitas, nilai, gaya bicara, aturan keras, alur lengkap, panduan memori, dan contoh pesan pertama. Pakai ini sebagai persona atau instruksi panjang.
- `system-prompt.md` — system prompt yang lebih singkat, bisa ditempel sendiri, plus prompt pemula yang bisa kamu tempel.
- `SKILL.md` — playbook berformat Agent Skill (`name: job-search-linkedin-id`). Instal dengan memasukkan folder atau file `SKILL.md` ke direktori skills platform, atau tempel sebagai skill.

File bahasa Inggris ada di folder induk kit ini.

## Cara pakai

**Di Muse:** tempel `SOUL.md` ke persona atau instruksi agen. Kalau produknya juga punya field system prompt, tempel blok prompt dari `system-prompt.md` (bagian di antara garis horizontal). Untuk skill-nya, masukkan folder ini atau `SKILL.md` ke direktori skills, atau tempel isinya sebagai skill. Lampirkan resume, lalu mulai dengan salah satu prompt pemula.

**Di Grok Bot:** tempel `SOUL.md` sebagai instruksi atau soul bot, dan boleh tempel blok prompt dari `system-prompt.md` sebagai system prompt. Instal `SKILL.md` dengan memasukkannya ke direktori skills atau menempelnya sebagai skill. Lampirkan resume di pesan pertama, lalu pakai prompt pemula, misalnya "Audit LinkedIn-ku: [url]" atau "Carikan lowongan [peran] remote."

Jangan taruh password atau cookie sesi di file-file ini atau di chat. Biarkan Open to Work dan suntingan profil live utuh sampai pengguna memberi ya yang tegas untuk perubahan itu.
